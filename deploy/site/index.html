The problem

Disasters bring thousands of claims at once, and most go unreported or unpaid.

After El Niño’s rains, people file from flooded homes with no power and no office to visit. Reports arrive incomplete, and when two people are involved, their stories don’t match.

One number, two paths

Every claim starts with one tap.

After the injury question, the person picks a path with a WhatsApp reply button. The choice is saved in code, so no step can be skipped.

Con otra persona · With someone else

A neutral joint report

After a crash, both people message the same number, each in their own chat and language. Claimline compares the two versions in plain code, asks only about what doesn’t match, and never says who is at fault. Both approve the report in a WhatsApp Flow and receive the PDF.

Solo yo · Just me

A loss of one’s own

A home or shop flooded in the El Niño rains. The agent asks for a location pin, when it happened, how high the water got and what was damaged, then sends the report to approve. One approval closes the case and the PDF arrives in the chat.

How it works

From a voice note to an adjuster’s map in minutes.

Report

Text, voice notes (Amazon Transcribe), photos and a location pin, any time, in Spanish or English.

Collect each fact

A Strands agent on Bedrock AgentCore asks one question at a time and saves every fact with the person’s own words as evidence.

Compare in code

Each fact is AGREED, ONLY_A, ONLY_B or CONFLICT. Claude only judges whether two free-text values mean the same; no AI decides fault.

Approve

Each person reviews the draft in a WhatsApp Flow. Approving means “this records what I said”, not “I accept the other version”.

PDF

The report is built in code as a PDF, stored in S3 and sent back in the same chat.

Claims board

The insurer sees every case on a live map, with the whole conversation, the facts, the comparison and the PDF.

Built on research

Each finding became a rule in the code.

FindingWhat Claimline does
Witnesses who talk to each other pick up details they never saw (Gabbert et al., 2003–2006)Each person reports in their own chat and never sees the other’s answers
One loaded verb changes remembered speed and invents broken glass (Loftus & Palmer, 1974)Neutral questions; the agent never suggests a speed, a cause or a fault
Agreement between witnesses can be contamination, not proofPlain code compares the facts and asks only about conflicts
A chatbot gets more informative, specific answers than a web form (Xiao et al., 2020)WhatsApp, one question at a time, the person’s own words saved
Being kept informed is what keeps claimants (J.D. Power, 2019–2025)Approval and the PDF arrive in the same chat
Built on AWS

Serverless, pay per use, one command to deploy.

The whole stack is AWS CDK and deploys into the insurer’s own account. With no traffic, it costs almost nothing; in a flood it scales with the claims.
