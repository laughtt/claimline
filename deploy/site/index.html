One person or two

Any claim is one of two shapes. One tap picks the path.

After the injury question, Claimline sends two WhatsApp buttons. The choice is saved in code, so no step is skipped, and the same engine serves every line of insurance.

Fair comparison

A crash in the El Niño rain: two versions, compared in code.

Each fact is labelled AGREED, ONLY_A, ONLY_B or CONFLICT by plain code. Claude only judges whether two free-text values mean the same thing. The agent asks once about each conflict, in neutral words, and never says who is right.

How it works

From a voice note to an adjuster’s map in minutes.

Report

Text, voice notes (Amazon Transcribe), photos and a location pin, at any hour, in Spanish or English.

Safety first

The first question is whether anyone is hurt. If so, the agent gives the emergency number and hands the case to a person.

Collect each fact

A Strands agent on Bedrock AgentCore asks one question at a time and saves every fact with the person’s own words as evidence.

Compare

With two people, plain code compares both versions and the agent asks only about conflicts.

Approve

Each person reviews the draft in a WhatsApp Flow. Approving means “this is what I said”, not “I accept the other version”.

PDF and board

The report is built in code as a PDF and sent in the chat. The insurer sees the case on its claims board.

The insurer’s side

Every claim on a live map, with the whole conversation.

When the rain hits Piura, adjusters see where the damage is, which cases are approved, which have conflicts, and can open any conversation, fact and PDF.
